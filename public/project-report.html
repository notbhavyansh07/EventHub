1. Executive Summary & Objective

EventHub is a full-stack web application developed to modernize the discovery, registration, and attendance tracking of collegiate events, workshops, technical talks, and hackathons.

The platform addresses key inefficiencies in campus activity coordination, including manual paper-based attendance, race conditions during high-demand workshop seat registrations, fragmented communication, and lack of real-time seat transparency for attendees.

2. Technical Architecture & Stack

Layer Technologies & Libraries Key Purpose
Frontend HTML5, CSS3, JavaScript (Fetch/AJAX, ES6 Modules) Single-page interactive experience, responsive UI crafted with strict unslop design guidelines.

3. Core System Features

3.1 Student Attendee Experience

  • Frictionless Onboarding: Instant account registration with automatic session creation and homepage redirection.
  • Real-time Seat Tracking: Live attendance capacity indicators with visual warning thresholds (>80% filled).
  • Atomic Concurrency-Safe RSVP: SQL database transactions with row-level locks preventing double-booking of final seats.
  • Digital QR Boarding Pass: Instant generation of an interactive boarding pass modal containing attendee metadata and a unique QR ticket ID.
  • Add to Google Calendar: 1-click calendar export that synchronizes event timings, description, and campus venue directly to Google Calendar.
  • Social & Peer Sharing: Native Web Share API integration with automatic fallback to clipboard copy.

3.2 Administrator & Organizer Dashboard

  • KPI Statistics Overview: Real-time overview of total events, active registrations, student count, and upcoming sessions.
  • Full Event Lifecycle Management: Admin capabilities to create, edit, update capacity, and delete events.
  • Participant Roster & CSV Export: Instant attendee inspector with one-click export of registered students to spreadsheet-ready .csv files.
  • Role-Based Access Control (RBAC): Server-enforced middleware blocking unauthorized API requests with 401 Unauthorized and 403 Forbidden statuses.

4. Database Schema Design

The relational database enforces data integrity through three primary tables:

  • users: Stores authentication credentials, full name, email, encrypted password_hash, and authorization role (user | admin).
  • events: Stores event title, description, venue, category, scheduled datetime, seating capacity, and organizer ID.
  • registrations: Junction table linking user_id and event_id with a composite UNIQUE (user_id, event_id) constraint to prevent duplicate registrations, with ON DELETE CASCADE rules.

5. Software Engineering Best Practices & Quality Assurance

Automated Test Coverage: 21 automated unit tests written for Node.js native test runner (node --test) verifying authentication guardrails, input validation, date formatting, capacity limits, and transactional rollbacks.
  • Zero SQL Injection: 100% parameterised SQL queries across all controllers.
  • Cross-Site Scripting (XSS) Mitigation: Client-side sanitization and HTML entity escaping before rendering user-generated content.
  • Session Fixation Protection: Invocation of req.session.regenerate() upon successful credential validation.
  • Unslopped UI Standards: Built following the heydamir/unslop design methodology featuring a disciplined neutral ink palette, strict 4px grid spacing, and accessible contrast ratios.

6. Conclusion

EventHub delivers a production-grade campus event registration solution that bridges aesthetic design with robust backend engineering. The system has been successfully verified, unit-tested, and deployed live to Render under continuous deployment.
